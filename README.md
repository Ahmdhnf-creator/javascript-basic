# 💻 Persiapan

Pastikan sudah menginstall:

- Visual Studio Code
- Node.js
- Git
- GitHub Account

Cek instalasi:

```bash
node -v
```

```bash
git --version
```

# 🍴 Cara Mengerjakan Tugas

## 1. Fork Repository

Klik tombol **Fork** pada repository ini.

---

## 2. Clone Repository

```bash
git clone https://github.com/arifwardan/javascript-basic.git
```

Ganti `USERNAME` dengan username GitHub milikmu.

---

## 3. Masuk ke Folder Project

```bash
cd javascript-basic
```

---

## 4. Kerjakan Latihan

Contoh:

```
bab-03-variable/
```

Masuk ke folder latihan.

```
latihan-01/
```

Lalu kerjakan file

```
index.js
```

---

## 5. Jalankan Program

```bash
node index.js
```

Pastikan program berjalan tanpa error.

---

## 6. Commit Perubahan

```bash
git add .

git commit -m "Menyelesaikan Bab 3 - Latihan 1"
```

---

## 7. Push ke GitHub

```bash
git push origin main
```

# 📏 Aturan Selama Belajar

✅ Gunakan `const` jika nilai tidak berubah.

✅ Gunakan `let` jika nilai berubah.

❌ Jangan menggunakan `var` kecuali diminta.

✅ Gunakan penamaan variabel dengan format **camelCase**.

✅ Rapikan kode sebelum melakukan commit.

✅ Jangan menghapus file yang sudah disediakan.

---

# 🧹 Standar Penulisan Kode

Contoh yang baik:

```javascript
const namaLengkap = "Budi";
const umur = 20;

console.log(namaLengkap);
console.log(umur);
```

Contoh yang kurang baik:

```javascript
var Nama = "Budi";

var x = 20;
```
