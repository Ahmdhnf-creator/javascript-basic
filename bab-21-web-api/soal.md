# 📝 Latihan Bab 19–21: Sistem Data Pengguna

## 🎯 Study Case

Buat sebuah aplikasi web sederhana untuk menampilkan dan mengelola data pengguna.

Aplikasi akan mengambil data pengguna secara asynchronous, mengolah data JSON, kemudian menampilkannya ke halaman.

Materi yang digunakan:

- JSON
- `JSON.stringify()`
- `JSON.parse()`
- Promise
- `async / await`
- `try...catch`
- Fetch API
- DOM
- `localStorage`
